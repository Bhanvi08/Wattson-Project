WATTSON: AI ENERGY ANALYTICS AND FAULT DIAGNOSTICS

Wattson is an intelligent energy management platform designed to bridge the gap
between electrical hardware data and software analytics. This project provides a
real time dashboard for power consumption and cost estimation alongside an AI
driven fault diagnostic engine.


INTRODUCTION

Most energy consumers lack the tools to understand their consumption patterns or
identify household electrical risks. I built Wattson to act as a virtual
technical assistant that handles data tracking and safety diagnostics. The
system uses a Python backend to process meter data and provide human like
explanations for complex electrical issues.


CORE TECH STACK

  - Backend: Python and Flask framework
  - Frontend: HTML CSS and JavaScript
  - Analytics: Chart.js library
  - Environment: Isolated Python environment with UV


SYSTEM ARCHITECTURE

  - Energy Analytics: Real time tracking of kWh units with integrated tariff
    slab logic for billing
  - AI Diagnostics: A rule based analytical engine that processes reported
    symptoms like MCB trips or high bills
  - Technical Assistant: An NLP assistant using keyword mapping for electrical
    safety and troubleshooting
  - User Data Management: Personalized profile system with persistent data
    across the application session


ENGINEERING LOGIC EMPLOYED

The system is built on core Electrical Engineering principles to ensure
technical accuracy:

  - Efficiency Modeling: Analysis based on BEE Star Ratings and thermal
    equilibrium
  - Fault Diagnostics: Troubleshooting flows for Short Circuits and Earth
    Leakage and Neutral faults
  - Consumption Math: Implementation of the energy formula (Power in Watts *
    Time in Hours) / 1000
  - Power Quality: Advice on power factor optimization and load shifting for
    peak hours


FUTURE ROADMAP

  - Hardware Integration: Connecting the Flask engine to ESP32 and IoT current
    sensors for live data
  - LLM Integration: Moving from heuristic logic to a full LLM API for complex
    technical queries
  - Mobile Deployment: Developing a cross platform mobile instance for real time
    energy alerts
